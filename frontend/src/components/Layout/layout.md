# Layout 目录说明

应用全局布局与导航组件。

## 组件文件
- `Layout.jsx`：主布局容器，包含顶部导航、侧边栏与内容区域。
- `Menu.jsx`：侧边导航菜单组件，支持多语言与权限控制。
- `NotificationCenter.jsx`：全局通知中心组件，展示系统消息与操作反馈。

## 功能职责（Functional）
- 顶部导航、侧边栏、页脚、面包屑等布局结构。
- 提供路由容器与通用页面框架。

## 非功能性要求（Non-Functional）
- 一致性：布局组件需保持全站视觉与交互一致。
- 响应式：支持桌面与常见分辨率适配。

## 约定与规范
- 布局只处理结构与导航，不写具体业务逻辑。

# BacktestHistory 目录说明

回测历史与详情展示模块组件。

## 组件文件
- `BacktestDetailModal.jsx`：回测详情弹窗，展示收益曲线、交易记录与绩效指标。

## 功能职责（Functional）
- 展示回测列表、过滤、分页、详情弹窗/图表等。
- 支持查看收益、指标、交易记录与策略可视化。

## 非功能性要求（Non-Functional）
- 性能：列表与图表需避免阻塞 UI；大数据量使用分页/懒加载。
- 可用性：指标/时间序列展示需清晰可解释。

## 约定与规范
- 与回测结果数据结构保持一致，变更需同步后端 `routes` 与 `service` 约定。

# assets 目录说明

静态资源根目录，用于存放图片、图标、插画、字体等不参与业务逻辑的资源。

## 功能职责（Functional）
- 提供应用 UI 所需的静态文件（logo、背景、占位图等）。
- 由组件或样式文件按需引用。

## 非功能性要求（Non-Functional）
- 体积控制：优先使用 SVG/WebP；大图需压缩并避免重复存储。
- 可缓存：文件名建议带版本/哈希或通过构建工具生成以利于缓存。
- 合规：确保资源版权清晰可用。

## 约定与规范
- 按类型/用途分子目录，命名语义化（如 `illustrations/`、`icons/`）。
- 不在此目录放业务 JSON/配置，避免与 `config/` 混淆。

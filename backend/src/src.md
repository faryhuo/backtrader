# backend/src 目录说明

本目录是后端服务源码根目录，基于 FastAPI 提供回测、策略管理、数据源、实盘交易与 AI 分析等能力。

## 功能职责（Functional）
- 路由层：`routes/` 定义 HTTP/WebSocket 接口与参数校验。
- 服务层：`service/` 组织应用启动、会话管理、回测/实盘引擎与业务编排。
- 持久层：`db/` 定义数据模型与存取封装。
- 适配层：`brokers/` 提供交易所/券商适配（如 CCXT、IBKR）。
- 配置与工具：`config/` 读取并校验环境配置；`utils/` 提供无状态通用工具。

## 非功能性要求（Non-Functional）
- 安全：所有密钥/账户信息必须来自环境变量或外部配置文件，不得写入代码库。
- 可靠性：路由层仅做校验与编排，业务失败要返回一致的错误结构。
- 性能：回测/行情处理避免阻塞事件循环；CPU 密集任务考虑后台执行。
- 可维护性：按层划分模块，避免跨层耦合与循环依赖。
- 可测试性：核心业务与适配器需可在 mock 外部依赖下测试。

## 约定与规范
- 新功能优先在 `service/` 形成清晰用例接口，再由 `routes/` 暴露。
- 新增环境变量必须同步更新 `backend/.env.template` 与相关文档。
- 不提交本地数据库/缓存到仓库（除非用于 demo/fixture）。

# 策略目录说明

本目录只存放**用户亲自维护**的交易策略脚本（如 `*.py`）与相关资料。默认情况下，AI 生成的代码不得直接修改、增删这些策略文件。

## 权限与责任
- 人工负责人：策略逻辑、风险控制与发布决策。
- AI 角色：仅在明确授权的需求下，提供文档优化、代码审阅或辅助脚本，不主动改动策略实现。
- 如需 AI 修改策略，请提前说明范围与期望，完成后务必人工复核。

## 文件与命名
- 策略脚本建议使用小写加下划线，如 `ma_cross.py`、`grid_trader.py`。
- 临时实验文件放入 `sandbox/` 或单独分支，稳定版本进入主目录。
- 如有依赖数据/配置，使用相对路径并在 README 中注明来源与用法。

## 变更流程
1. 人工编写或审阅策略改动，确认核心逻辑、风控参数、交易品种与时间框架。
2. 本地运行最小回测或沙箱验证（参见 `strategy_sandbox.py`），记录关键指标。
3. 通过 Git 提交，提交信息包含策略名、核心改动与验证结果。

## 安全与合规提示
- 禁止将真实交易密钥、账户信息或敏感配置写入仓库。
- 回测参数、滑点、手续费需与真实环境一致或明确差异。
- 对接实盘前再次人工复核风险边界与风控触发条件。

## 常见协作场景
- 需要 AI：编写/优化文档、提出代码审阅意见、生成测试用例框架。
- 不需要 AI：直接改动策略逻辑、调整交易参数、合并未审阅的策略代码。
